# 改方子（recipe-resize）

把一份配方从一个模具搬到另一个模具：先按**容积比**算出新方每一行该称多少克，再处理那件不能按比例缩的事 —— **鸡蛋不能切**。

- 页面：`index.html`（单文件，离线可用，不联网、不内置任何真实配方）
- 引擎：`core.js`（纯函数，浏览器与 node 通用；`window.AppCore`）
- 界面：`ui.js` + `template.html`，`node build.cjs` 合成 `index.html`
- 测试：`node --test tests/core.test.cjs`（57 项，手算锚点 + 独立对拍 + 随机压力 + 不变量）
- 发布说明数字回溯：`node 说明数字校验.cjs`（把 `说明.txt` 里每个数字查回同一次引擎输出）
- 浏览器验收：`node 验收脚本.cjs --tag 本地`（或 `--tag 线上 --url <线上地址>`）

## 模型（全部写在页面上）

1. 面积：圆 `πD²/4`；方 `长 × 宽`。体积：面积 × 侧壁内高。
2. **料量比** `k = 目标容积 ÷ 原容积 = 面积比 × 高度比`。两个模等高时 k 就是面积比 —— **不是直径比**。
3. 新方：`面粉′ = 面粉 × k`，每一行 `= 烘焙百分比 × 面粉′`。
4. 蛋液目标 `= 蛋数 × 每蛋克数 × k`；建议蛋数 = 四舍五入。两条收口：
   - **① 扣液体**：差额按各行原占比摊到勾选的液体行上，改完总液体守恒；
   - **② 按整蛋配平**：先定整蛋，再反推面粉，全方等比，代价是与目标 k 有偏差。
5. 取整：`round(x ÷ 刻度) × 刻度`（半格向上）或一律向上，只影响"照着称"那一列。

## 不做的事

不给烘烤温度与时间建议；不换算杯/毫升；不做心形、中空、异形模；不判断面糊该装几分满；
不内置任何真实配方、品牌或面粉吸水性；默认值是虚构示例。
